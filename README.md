# HaZardModding Coop: SiN Reloaded
HaZardModding Coop: SiN Reloaded is a free, open-source, non-profit project initiated by Chrissstrahl and developed by HaZardModding.
The modification is primarily driven by level scripts and does **not** modify any executables or DLL files.
It allows up to **4 players** to play through parts of the game cooperatively.

# 20 Years of Experience
SiN Reloaded Coop builds upon Chrissstrahl's 20 years of experience developing cooperative modifications for games built using Ritual Entertainment's ÜberTools technology.

# Carefully Hand-Coded with AI Assistance – No Vibe Coding Involved!
At least 100 hours of human development and testing have gone into this modification so far.
ChatGPT's estimated contribution to the overall development process is approximately 5%.
It was primarily used for technical research, debugging, documentation, generating new images, and enhancing screenshots and existing images.

This modification is brand new, with development started by Chrissstrahl on October 22, 2026.

Additional features will be introduced as development progresses.

# Usage
1. Download or clone the entire repository from the master branch.
2. Place the `coop` folder, including all its subfolders, **alongside** the `base` folder in your SiN Reloaded installation directory.
3. Add the following launch parameters to `sinreloaded.exe`:
   `+set game coop +set coop 1`
4. Launch SiN Reloaded, open the console, and enter:
   `coop 1;map bank`
5. To see the Coop console messages open the console, and enter:
`g_developer 128`
