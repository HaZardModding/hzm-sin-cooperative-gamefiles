# HaZardModding Coop: SiN Reloaded
A non-commercial fan project - Coop Mod for SiN Reloaded.

HaZardModding adds modern cooperative experience into the games, that don't support it by default.
This modification requires a legitimate copy of the original game, we recommend the Steam release.

We recommend the Steam relase because it offers additional Steam Internet Multiplayer.
You can't join a Steam Internet Server with the GOG release,
but you can join a GOG LAN Server with the Steam release.

https://store.steampowered.com/app/632950/SiN_Reloaded/


# Usage
1. Download or clone whole repository from master branch
2. Put the folder "coop" including all subfolders NEXT to the "base" folder of SiN Reloaded.
3. Set these additional start parameters for the sinreloaded.exe: +set game coop +set coop 1
4. Launch the SiN Reloaded, open the Console and type in "coop 1;map bank"
